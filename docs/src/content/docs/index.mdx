```ts title="zero.ts"
import { createDefinitions } from "zero-bindings";
import { VueBindings } from "zero-bindings/vue";

export const zero = VueBindings.create({
  definitions: createDefinitions({ schema, queries, mutators }),
  client: () => activeClient.value,
});

// main.ts
app.use(zero);

// component
const issues = zero.useQuery((queries) => queries.issue.all());
issues.data.value;
```

Use an existing Zero client from your framework app. `zero-bindings` gives you typed reactive queries and mutations without replacing your framework's state model.

## What you use

- `useQuery()` returns reactive `data`, `status`, and `error` values.
- `useMutation()` keeps pending, error, and client/server results together.
- Query arguments and options can follow framework state.
- Replacing the active Zero client updates active queries without changing component code.

The adapters own framework integration and cleanup. Your application keeps ownership of the Zero client, schema, authentication, and routing.
