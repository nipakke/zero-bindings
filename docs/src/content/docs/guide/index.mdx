Install the package, choose the adapter for your framework, and connect it to the Zero client you already use.

## Install

```sh title="Vue"
pnpm add zero-bindings @rocicorp/zero vue
```

```sh title="Svelte"
pnpm add zero-bindings @rocicorp/zero svelte
```

`@rocicorp/zero` is a peer dependency; this package supports `>=1.7.0 <1.10.0`. Install the framework peer only for the adapter you import.

## Before you start

Have these from your Zero setup:

- the Zero `schema`;
- a client, usually exposed through auth or application state;
- optional `queries` and `mutators` registries.

This package does not create the Zero client or schema. It connects those existing values to your framework.
