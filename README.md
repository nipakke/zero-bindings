# zero-bindings

Framework-neutral bindings for connecting Zero to application reactivity.

> [!WARNING]
> **Pre-1.0, unstable.** This package is at `0.0.x`. Until `1.0.0`, breaking changes ship in minor and patch releases without a major version bump and without a deprecation window. Pin an exact version and read the changelog before upgrading.

- [Documentation](https://zero-bindings.zhorna.workers.dev/guide)
- [API reference](https://zero-bindings.zhorna.workers.dev/api)
- [Development](https://zero-bindings.zhorna.workers.dev/development)

## Install

```sh
pnpm add zero-bindings @rocicorp/zero vue
# or
pnpm add zero-bindings @rocicorp/zero svelte
```
